# Decisions

| Date | Decision | Reason |
|---|---|---|
| 2026-11-03 | Docker present; `runsc` absent → `RUNTIME=runc` mode | Env detection on build machine. Gap: no gVisor isolation; use strace + internal network + cap-drop. |
| 2026-11-03 | Use Python 3.12 via `python3.12` in Makefile | Spec requires 3.12; system also has 3.13/3.14. |
| 2026-11-03 | Port existing root design files into `design/` then `web/` | Design already uploaded; keep class names per Part 1.8 / design README. |
| 2026-11-03 | Default `PROVISIONER=fake` and `LLM_MODE=fake` | No Vultr keys in env; everything must run offline with tests green. |
| 2026-11-03 | GitHub repo `lupong/toolpain` (public) | User requested repo named toolpain in their GitHub account. |
| 2026-11-03 | Authored `docs/ARCHITECTURE.md` from megaprompt §2.2–2.4 | Spec referenced the file but it was not in the upload; synthesize from Part 2. |
| 2026-11-03 | Add LLM probe-harness stage (repo context → JSON call plans) via Vultr Inference proxy | User asked for Inference to read the repo and produce a harness used by probing. Harness is data-only (args/watch hints), never exec'd as code. Fake mode uses `fixtures/harnesses.json`. |
| 2026-11-03 | decoy-trap-server uses `mcp.server.mcpserver.MCPServer` (mcp 2.x name for FastMCP) with a `FastMCP` import fallback | Installed `mcp` is 2.3; `mcp.server.fastmcp` no longer exists. |
| 2026-11-03 | `fetch_report` has no env/path override; locally the decoy file is simply absent | Keeps the safety contract literal: one fixed decoy path, one fixed sinkhole host. |
| 2026-11-03 | `runner/launch.local_launcher` refuses scripts outside `demo/` | Scanned servers must only ever run in a container; local run is demo/test-only. |
| 2026-11-03 | Discovery tool-name docs extraction: regex in fake mode (Tools-section bullets/tables/sub-headings + snake_case bullets); LLM extractor optional | Matches spec (fake mode = regex on README). |
| 2026-11-03 | Fork drift baseline for the demo = `demo/decoy-trap-server/upstream_tools.json` | No real upstream for the demo; honest tools are the "upstream" version. |
| 2026-11-03 | Trace with `strace -f -ttt` (epoch timestamps) instead of `-tt` | `-tt` gives time-of-day only; epoch timestamps correlate directly with call windows. Parser also accepts `-tt` with a base date. |
| 2026-11-03 | Sinkhole listens on a fixed port list (80,443,8080,8443,8000,3000,5000,9000,25,21,22) rather than every port | Avoids iptables/CAP_NET_ADMIN in the container; configurable via `SINKHOLE_PORTS`. TLS connections are logged by parsing SNI from the ClientHello (no cert needed). |
| 2026-11-03 | Sinkhole image has no pydantic; it emits JSON lines on stdout (`docker logs`) and the host parses them into `SinkholeRecord` | Keeps the image tiny (stdlib + dnslib). |
| 2026-11-03 | `fixture.local` resolves to the fixture-site container via a sinkhole DNS override; token page gets a per-scan decoy token substituted by the host | Everything else resolves to the sinkhole. |
| 2026-11-03 | Sandbox protocol has `on_call_complete(tool, start, end)`; real sandboxes no-op, `FakeSandbox` renders its fixture inside the call window and parses it with the real parser | Lets fake-mode probing exercise the same correlation code as Docker mode. |
| 2026-11-03 | Docker tests build `toolpain-decoy-trap:test` from `demo/decoy-trap-server/Dockerfile`; skip (never hang) when daemon/registry/build unavailable | First image pull can be slow; timeouts keep `make test` bounded. |
| 2026-11-03 | Probe correlation: event inside a call's `[start,end]` wins; otherwise attributed to the most recent call whose `end+500ms` tail covers it | Prevents a slow tail (e.g. sinkhole connect) from being stolen by the next call. |
| 2026-11-03 | Probe uses one MCP session per flag-group (default group + one per capability flag set) and retries once with all properties filled when the error looks like a schema/validation error | "Retry once on schema error" without hammering tools. |
| 2026-11-03 | Fake-mode research serves `runner/fixtures/tool_profiles.json` by tool name, else a keyword heuristic; control-plane `FAKE_TOOL_PROFILE` is not used by the runner | Deterministic per-tool profiles (the proxy fake is tool-agnostic). Live mode goes through `/internal/llm/chat`. |
| 2026-11-03 | Fixture hosts (`fixture.local`) are probe infrastructure: shown per tool as network but never counted as undeclared egress | Browser tools must reach the fixture site. |
| 2026-11-03 | Toxic combos may be single-tool (`tools: [x]`) when one tool holds both halves (e.g. decoy read + egress) | The demo's `fetch_report` is the only dangerous tool; pairs alone would miss it. Capped at 12 combos, sorted by severity. |
| 2026-11-03 | Privilege tier = union of *claimed* (name/description/schema keywords) and *observed* (probe) capabilities; `exceeds` = observed - claimed | A tool that does more than it says is tiered by what it does and gets `description_mismatch` / `exceeds_claim`. |
| 2026-11-03 | Overall verdict precedence: flagged (decoy/undeclared egress) > suspicious (undocumented, fork-added, hidden-flag, prompt injection, medium+ anomaly) > over_privileged (exceeds_claim) > clean | Follows ARCHITECTURE.md 4.6; critical-tier tools alone do not make a server over_privileged if they behave as documented. |
| 2026-11-03 | Fork drift needs an upstream tool list (`upstream_tools.json` next to the source, or `ScanConfig.upstream_tools`); none -> no drift | No git-upstream resolution yet (M7+). Demo baseline = honest tools. |
| 2026-11-03 | `runner.main.run_scan` uses `FakeSandbox` (local process, demo/ only) by default and `DockerSandbox` with `sandbox="docker"`; events/report go to the control plane only when `token` + `control_plane_url` are set; reporting failures are logged, never fatal | Spec M6 stub; keeps unit tests offline. |
| 2026-11-03 | Fetch/build/launch are packaged stages emitting data-only `RepoManifest` / `BuildPlan` / `LaunchPlan`; Dockerfiles come only from `runner/templates/`; git/docker/mcp trial use argv lists never shell-interpolated | Audit: repos vary wildly; LLM must not emit executable build/launch code. |
| 2026-11-03 | Override: LLM emits executable `launch_sh` + `probe_py` (`EXECUTABLE_SCAN_CODE`); `launch_sh` runs only inside the scan image; `probe_py` is AST-allowlisted then `exec`'d solely to obtain call plans | Product thesis: adaptive executable codegen for diverse MCP repos; containment replaces “JSON only”. |
| 2026-11-03 | Expand executable surface: `WORKDIR_PICK_CODE`, `next_plans` second probe round, `oracle_py` findings; optional `scan_brief` on intake as prompt context only | Repo + user-intent dynamics without a second trust domain; same AST allowlist. |
| 2026-11-03 | `sandbox=auto` → FakeSandbox for `demo/**`, else DockerSandbox after fetch+build+LaunchPlan trial; `local_path=None` clones `repo_url` | Makes LocalProvisioner + UI able to scan real GitHub URLs. |
| 2026-11-03 | `LLM_MODE=ollama` uses local Ollama OpenAI `/v1` (`llama3.2:latest`); Cursor's xg-ai ollama MCP was unreachable so ToolPain talks to Ollama directly via the control-plane proxy | Real local harness/profile JSON without Vultr. |
| 2026-11-05 | Demo pacing is 2.5s per stage beat and 0.8s per tool probe when `delay_sec` is unset; tests pass a small `delay_sec` | Keeps a fake scan in the 30–45s watch window without slowing pytest. Alert events fire only for tools that actually read a decoy. |
