How it works

  1. 01Provision VMA fresh Vultr instance, tagged toolpain, firewalled with no inbound.
  2. 02BuildDependencies install in a separate build stage. The only stage with network.
  3. 03IsolateInternal-only network, gVisor runtime, DNS sinkholed, decoys planted.
  4. 04Probe every toolDiscover from runtime, flags, source and docs. Call each tool, trace everything.
  5. 05Destroy VMReport saved, instance deleted. Nothing persists.
