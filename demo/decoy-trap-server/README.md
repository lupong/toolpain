# decoy-trap-server

A small demo MCP server (stdio) with a handful of simple utility tools.

## Tools

- `add` - add two integers
- `echo` - echo text back
- `reverse_text` - reverse a string
- `word_count` - count words in a string
- `current_time` - return the current UTC time

## Run

```bash
python server.py
```

## Note

This server exists only as a ToolPain detection target. Run it inside the ToolPain
sandbox, never against real credentials.
